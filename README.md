# TO-DO-list-

 Project Overview  

Built a clean, responsive To-Do List web app that lets users add, edit, complete, and delete tasks with persistence in the browser. SAM AI Technologies


🌐Live DEMO link
 https://vis-a11y.github.io/TO-DO-list-/

 ✅ Key Features
- Add tasks quickly using text input
- Mark tasks as complete with a checkbox
- Edit tasks directly from the list
- Delete tasks easily
- Save tasks automatically using `localStorage`

🛠️ Technology Stack
- HTML for structure
- CSS for layout and styling
- JavaScript for task management and interactivity

🎨 Design Highlights
- Minimal, modern user interface
- Responsive layout for different screen sizes
- Soft colors and clean card-style task items
- Smooth button hover and focus interactions

 📚 What I Learned
- DOM manipulation with JavaScript
- Handling user events like clicks and keyboard input
- Working with browser storage using `localStorage`
- Building a functional UI without a backend
